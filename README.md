## [CodeBPE](https://github.com/kmfarris/CodeBPE): byte-pair encoding over stable word codes

Language models read text as **tokens**, produced by byte-pair encoding (BPE): starting from characters, the most frequent adjacent pairs are merged again and again. The resulting tokens are statistical fragments. They rarely line up with word boundaries, and a one-word edit can change how the surrounding text is tokenized, so it's hard to trace which tokens a word produced or to change one word in token form.

CodeBPE gives every vocabulary word a fixed, collision-free code (a bucket and a slot) and spells out unknown words after an escape marker, so encoding is always lossless. BPE then merges those word codes instead of raw characters. To isolate the tokenizer's effect, two language models with identical architecture were trained on the same WikiText-2 data, one on standard text BPE and one on CodeBPE.

Decoding reproduced the original text exactly, and a one-word edit was pinpointed exactly in every test. At matched model size, the CodeBPE model reached 1.76 bits per character on held-out text, against 1.88 for text BPE, which is 6% lower. CodeBPE packs held-out text less tightly than text BPE because more unseen words have to be spelled out, and it hasn't yet been compared against SentencePiece or tested beyond small scale.

## [IMOL](https://github.com/kmfarris/imol): a programming language built for AI coding assistants

When an AI assistant writes or edits code, it usually produces text that gets pasted straight into a file. Mistakes surface later, sometimes after the program has already changed files or reached out to the internet. Edits that point at "line 40" break as soon as anything above them moves.

IMOL gives every part of a program a permanent name tag, so an assistant can say "replace this function" instead of "replace line 40." Before anything is saved, IMOL checks the program and reports mistakes in a form the assistant can read and fix. Each program must state up front what it's allowed to do, such as reading files, writing files, using the internet, or running commands. A rehearsal mode lists every action the program would take without doing any of them. Nothing real happens until a person approves.

All of the tools work, the automated tests pass, and IMOL connects to the Cursor code editor. It isn't yet available as an installable package.

## [inference-time-conscience](https://github.com/kmfarris/inference-time-conscience): an SNN conscience for inference-time alignment

A large language model takes its tone and values from its context window. Every new turn adds to that context, and the model re-derives how it should behave from the conversation so far, so the original instructions carry less and less weight. The conversation shapes the conscience. That's how long chats drift and how multi-turn jailbreaks work.

This project reverses that direction: the conscience shapes the conversation. It runs alongside the language model, keeps its own state outside the context window, and changes only through slow, gated learning, so no single turn and no amount of accumulated context can rewrite it. A spiking neural network (SNN) holds a set of core values and a list of value violations. At every token, it excites value-aligned words and inhibits words that would violate those values, and the result is added to the language model's next-token scores before a word is chosen. The language model still writes the sentence. The conscience shifts the probabilities at every step, and it can be turned off to measure exactly what it contributes. Training data comes from a conscience curriculum of grounded preferred and rejected answers, generated by a local teacher model that rejects bad output automatically.

On held-out lessons, steering raised the output's match to the aligned reference answer from 0.0 to 0.1125. In an eight-turn conversation that pushes Qwen2.5-0.5B-Instruct toward hostile language, a values-stating system prompt alone let violation words through in about one reply in four; with the conscience's inhibition active at strength 4 or above there were none, and the replies stayed fluent. The conscience still blocks words rather than stance, and its bias strengths are set by hand. The planned next step is LoRA fine-tuning of an open-weight model on the curriculum, with the conscience active during training.
